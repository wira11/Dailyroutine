
```bash
npm run dev
```

## ❓ Common Questions

**Q: Do I need to create an account?**
A: No! Everything is stored locally on your device.

**Q: Will my data be synced across devices?**
A: Not in v1. That's planned for v2.

**Q: Can I export my data?**
A: Yes! Open browser console and type `window.devTools.downloadData()`

**Q: Is it mobile-friendly?**
A: Yes! Fully responsive design.

## 🐛 Troubleshooting

### "npm: command not found"
→ Install Node.js from https://nodejs.org

### "Port already in use"
→ Run: `npm run dev -- --port 3000`

### Need sample data?
→ Console: `window.seedSampleData()`
